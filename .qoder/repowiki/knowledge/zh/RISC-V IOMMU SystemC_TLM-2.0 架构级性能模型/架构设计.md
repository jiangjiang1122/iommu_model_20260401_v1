- 顶层入口 `main.cpp` 通过 `sc_main` 实例化 `iommu_top`、`RP_Module`、`PCIENOC_Module`、`SLINK_Module`、`DDR_Module`，并以 TLM `simple_initiator_socket` / `simple_target_socket` 绑定 AXI/NoC 路径。
- `iommu/iommu_top.hh/.cc` 是核心 SystemC 模块，内部维护 ~21 个 `SC_THREAD`（Parser → Collector → xDTW/PT Cache/MSIPT Cache → PTW/MSIPTW → Forwarder/Fault/CQ），各阶段通过命名化的 `sc_fifo<iommu_task_t*>` 传递任务，使用 `tlm_utils::peq_with_get` 实现非阻塞并行时序建模。
- 缓存子系统 `iommu/cache_src/subsystem/cache_subsystem.h` 以 `CacheSubsystem` 聚合 `DCCache/PCCache/PTCache/MSIPTCache/WalkerCache`，对外暴露统一的 `CacheMessage` FIFO 接口（request/update/invalidate + response），并通过 `GlobalConfig` JSON 配置容量、关联度与替换策略（PLRU/SRRIP）。
- 功能层 `iommu/iommu_fun_model/` 实现 ATC/ATS/故障/中断/MSI 翻译、进程上下文、二阶段翻译等；性能层 `iommu/iommu_perf_model/` 提供寄存器模型、命令队列、设备上下文、性能收集器、任务-缓存消息转换器 (`iommu_task_cache_convert`)。
- 外设仿真：`rp/` (Root Port 请求生成)、`pcienoc/` (PCIe NoC 转发)、`slink/` (IOMMU→DDR 控制路径 NoC)、`ddr/` (内存响应)，均位于根目录独立子包。
- Walker Cache 在现有三级子表（PTWc_1/2/3）基础上扩展 S2 Cache 子表：通过 `WalkerTag.is_s2` 标志位隔离 S2 与常规 cache entry，`lookup_s2()/update_s2()` 以 GPA 为 key 缓存显式 G-stage 中间 walk 结果，由 `TEST_CFG_WALKER_CACHE_S2_ENABLED` 编译期开关控制启停，目标是将 GS_EXPLICIT 的 DDR reads 从固定 4 次优化为 1~4 次。
