- **顶层集成**: `iommu_top` 作为 SystemC 顶层模块，通过 TLM sockets 连接 PCIe NoC、DDR 和 Root Port 仿真模块，内部采用多阶段流水线架构。
- **流水线设计**: 包含 Parser、Collector、xDTW（设备/进程上下文遍历）、PTW（页表遍历）及 Forwarder 等核心线程，通过 `sc_fifo` 进行任务传递与同步。
- **缓存子系统**: `CacheSubsystem` 统一管理 DC、PC、PT、MSIPT 及 Walker Cache，支持配置化的替换策略（PLRU/SRRIP）和精细的时序建模。
- **数据转换层**: `iommu_task_cache_convert` 模块负责在 IOMMU 任务结构 (`iommu_task_t`) 与缓存消息 (`CacheMessage`) 之间进行语义映射，解耦功能逻辑与缓存实现。
- **配置驱动**: 通过 JSON 配置文件 (`default_config.json`) 动态加载缓存容量、关联度及延迟参数，支持不同测试场景的快速切换。
